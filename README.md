# 文献工作台

文献工作台是一款面向 Windows 的本地文献管理桌面应用。个人文献库、PDF、批注、笔记与翻译缓存保存在用户自己的电脑上；检索公开学术来源、获取开放全文和调用 AI 阅读助手时才需要联网。

当前源码版本：**0.9.27**。项目仍在积极开发，接口和数据格式可能调整。

## 功能

- 导入与去重：导入题录和 PDF，按集合、标签、智能集合整理文献；Chrome/Edge 扩展可采集当前论文网页。
- 发现与比较：检索公开学术来源，按条件核对候选文献；从本地资料中查看引用关系、比较多篇论文并记录证据。
- 阅读与写作：连续阅读 PDF、双栏对照翻译、选区批注与笔记、术语表、原文问答；通过本机 Word 加载项插入动态引用。
- 期刊选投：查询本地期刊索引并查看来源明确的指标。期刊源数据不随源码或安装包提供。
- 数据管理：SQLite 个人库、本机附件存储、备份与恢复。AI 访问密钥使用系统加密存储，不写入文献库。

本项目不是 Scholay、CNKI、Elsevier、Zotero 或其他学术平台的官方客户端。网页采集与全文获取受来源网站的访问权限和使用条款约束；请仅处理你有权访问和保存的内容。

## 从源码构建

需要 Windows x64、Python 3.12、Node.js 24 和 npm。PowerShell 在仓库根目录执行：

```powershell
./build-desktop.ps1 -InstallDependencies
```

脚本安装锁定的依赖、运行测试，并在 `dist/desktop` 生成安装包与便携版。以后依赖未变时运行 `./build-desktop.ps1` 即可。开发环境的启动、测试与目录结构见 [开发指南](docs/开发指南.md)；日常操作见 [使用指南](docs/使用指南.md)。

首次启动会建立空的个人文献库。AI 功能需要用户自行在“设置 → 阅读助手”填写兼容服务地址、模型和密钥；仓库不包含密钥、个人文献、论文 PDF 或已采集的期刊数据库。

## 数据与第三方材料

Git 仓库只包含源码、合成测试数据和构建所需资源。`library/`、`data/`、`backups/`、`docs/verification/`、构建产物和本机凭据被排除。不要将这些目录或第三方全文手动加入提交。

内置的 CSL 中文区域文件与 GB/T 7714 样式来自 Citation Style Language 项目，单独遵循其许可；来源和署名见 [CSL NOTICE](desktop/electron/csl/NOTICE.md)。其余依赖各自遵循上游许可证。
