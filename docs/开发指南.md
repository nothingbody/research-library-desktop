# 开发指南

## 目录

| 路径 | 作用 |
| --- | --- |
| `desktop/src/` | React 界面、PDF 阅读器和交互 |
| `desktop/electron/` | Electron 主进程、受限 IPC、浏览器扩展和 Word 桥接 |
| `client_backend/` | Python 本地服务、SQLite、全文索引和联网适配 |
| `tests_client/`、`desktop/tests/` | 后端与前端测试 |
| `build-desktop.ps1` | 测试和 Windows 打包入口 |

Electron 主进程通过 stdin/stdout 的逐行 JSON 与 Python 子进程通信。Renderer 无 Node 权限；本机文献库不会作为公网 HTTP 服务开放。运行数据和构建产物均在 `.gitignore` 中排除。

## 开发运行

Windows x64 上安装 Python 3.12、Node.js 24、npm 与 PowerShell 7（`pwsh`）。首次初始化：

```powershell
python -m venv .venv-client
./.venv-client/Scripts/python.exe -m pip install -r requirements-client.txt -r requirements-async.txt
cd desktop
npm ci
npm run build
npm start
```

`npm start` 启动 Electron 并调用根目录的 Python 虚拟环境。默认开发库为仓库根目录的 `library/`；请不要把真实个人库作为自动化测试库。仅运行 `npm run dev` 会打开没有本机 IPC 的 Vite 页面，不能验证完整功能。

## 测试

在仓库根目录运行后端测试：

```powershell
./.venv-client/Scripts/python.exe -X utf8 -m unittest discover -s tests_client
./.venv-client/Scripts/python.exe -X utf8 -m unittest test_collect_scholay test_robust_collector test_partition_collector test_async_runtime
./.venv-client/Scripts/python.exe scripts/publication_check.py
```

在 `desktop/` 运行前端和主进程测试：

```powershell
npm run test:main
npm run test:journal
npm run test:search
npm run test:writing
npm run test:browser
node --experimental-strip-types --test tests/translationLayout.test.mjs
npm run build
```

Electron 端到端脚本位于 `desktop/electron/*-smoke.cjs`，部分脚本需要隔离测试库、公开测试 PDF 或自行配置的模型密钥。不要在真实个人库上执行会写入条目、批注或笔记的 smoke 测试。

## 打包

根目录运行 `./build-desktop.ps1`。脚本使用 PyInstaller 打包 Python 服务，再用 electron-builder 生成安装包和便携版。期刊源库、个人文献库、PDF、模型密钥和验收输出都不会被打进应用。

浏览器扩展源码位于 `desktop/electron/browser-extension/`，安装包会将其复制到 `resources/browser-extension/`。Word 加载项清单位于 `desktop/electron/office-addin/`。
