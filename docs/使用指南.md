# 使用指南

## 安装、升级与卸载

安装版会登记在 Windows“已安装的应用”，便携版无需安装。运行新版本安装包可升级已安装版本；先关闭文献工作台，再选择原来的安装模式和目录。交互与静默升级会沿用经验证的旧目录。请使用专用程序目录，不要选择已有资料目录、磁盘根目录或目录链接。命令行安装中的 `/D=路径` 必须放在最后，路径不加引号，路径中可以包含空格。

旧版本的卸载器会删除整个安装目录。0.9.47 的安装程序会先检查旧目录；若其中存在文献库或其他未知文件，会停止升级，请先把这些资料迁到程序目录之外。即使选择另一个新安装目录，也仍会卸载登记的旧版本，不能用改目录来跳过资料迁移。

0.9.47 起的卸载器只删除构建时登记的程序文件，其他文件及包含它们的目录保留。默认位于 Windows“文档/文献工作台”的个人库、托管 PDF、笔记、翻译缓存和用户设置不会随正常卸载删除。保留这些数据是为了再次安装后继续使用；它们不代表旧版本程序仍然安装。个人库应始终保存在程序目录之外，设置中的目录选择也会阻止把新库建在程序目录内。

若其它程序仍占用某个程序文件，卸载会报错并停止，保留个人资料和安装标记，关闭占用程序后可重试卸载。此前已经移除的程序文件不会自动恢复；需要继续使用时请重新安装修复。

卸载本程序时，仅移除仍指向当前安装的网页唤醒入口，不会覆盖另一安装的入口。便携版、开发版和直接运行 `win-unpacked` 的程序不注册这个入口。浏览器扩展通过桌面端提供的用户数据目录加载；升级后在 Chrome/Edge 扩展管理页重新加载，卸载后可按需从浏览器移除该扩展。

## 建立文献库

首次运行后，应用会建立本机个人文献库。在“我的文献”中导入题录或 PDF，核对题名、作者、年份和 DOI 后保存。重复检测会提示已有条目；可用集合、标签和智能集合整理资料。设置中可以切换文献库目录并创建备份。

## 检索与采集

在“AI 文献检索”输入研究问题并按 Enter，即可自动生成检索式、检索公开学术来源并查看简洁结果表，不需要逐篇先做纳入决定。点击题名打开论文简介；配置了 AI 服务时，应用只为外文题录自动翻译来源提供的题名、摘要和关键词，并将译文保存在本机；中文题录直接显示原文。此操作会把这三项公开题录字段发送到所配置的模型服务；来源缺失的摘要或关键词不会由模型编造。点击“解析并阅读 PDF”会保存题录、获取可公开访问的 PDF，待文字解析完成后打开阅读器。保存检索结果时默认在后台获取开放 PDF；“有开放链接”仅表示发现候选地址，不保证站点会返回可下载的 PDF。复杂条件、人工筛选和来源证据可在高级区域展开核对。网络来源可能缺摘要、全文或某些指标，请以来源页面为准。浏览器扩展源码在 `desktop/electron/browser-extension/`；在 Chrome/Edge 扩展管理页开启开发者模式后，选择“加载已解压的扩展程序”并指定该目录。使用安装版时，可在“设置 → 浏览器采集”打开用户数据目录中的稳定扩展目录；若原扩展指向已删除的旧安装路径，请在扩展管理页移除旧版并从新目录加载一次。扩展可读取 JSON-LD、COinS、同站点 unAPI MODS 和 RIS 引文链接；在识别到多篇的检索页，勾选条目即可批量入库。知网检索结果会在保存时逐篇补全详情；批量采集上限为当前页前 50 条。

结果页默认展开完整列表，可从顶部打开检索历史。列表上方可切换排序、筛选开放链接；每条题录会标明来源及摘要可用情况。勾选本页文献后，批量保存与关联操作会出现在列表上方。论文简介的保存和阅读入口位于摘要之前。

浏览论文详情页时点击扩展，先核对题录、集合和 PDF 来源，再保存到本机文献库。扩展会识别主流期刊站点当前文章的 PDF 入口；部分站点由浏览器使用当前登录会话下载，完成后验证 PDF、导入并索引。浏览器下载的原文件仍保留在系统下载目录。识别到入口不保证下载成功；付费墙或机构认证内容需要用户自己拥有相应权限。

## 阅读与整理

双击库内 PDF 开始阅读。左侧主导航和页面缩略图可分别折叠；连续阅读、缩放、选中文字、批注和笔记均在阅读器内操作。阅读器会检查前几页的文字：中文文献直接显示原文，不自动翻译；外文文献默认打开双栏对照翻译，当前页译文缓存在本机。用户可在术语表中指定译名，随后打开受影响页面时会按新术语重新生成一次译文。

阅读助手可对选中的单词、句子、段落或可索引的页面进行翻译、总结、分析和讲解。先在“设置 → 阅读助手”填写兼容服务地址、模型及访问密钥并测试连接。AI 回答可能有误，重要结论应回到原文核对。模型请求会发送用户明确选择的材料；密钥由系统加密存储，不写入文献库。

“多文献问答”和“研究关联”用于对比库内论文及其证据。引用、主题相近或模型分析得到的联系应分别核对，不能把推断当作已证实的引用关系。

多文献问答优先为每篇所选文献提供一段相关材料，再补充其他片段。回答会显示实际使用的文献数和片段数；未找到材料的文献会列出题名，便于补充全文或调整来源。显示覆盖某篇文献，表示本次使用了该文献的片段，不代表模型已经通读整篇论文。

## 期刊与写作

期刊选投需要用户自己提供可用的本地期刊源库；源码与安装包不附带第三方数据库。期刊指标保留来源和年份，缺失数据不会自动推断。Word 加载项可插入和刷新引用，当前不提供 WPS 集成。

本机备份包含题录、托管附件、笔记、批注与阅读记录。重要文献建议定期备份到独立磁盘，并使用设置中的校验功能检查备份。
