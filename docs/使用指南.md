# 使用指南

## 建立文献库

首次运行后，应用会建立本机个人文献库。在“我的文献”中导入题录或 PDF，核对题名、作者、年份和 DOI 后保存。重复检测会提示已有条目；可用集合、标签和智能集合整理资料。设置中可以切换文献库目录并创建备份。

## 检索与采集

在“AI 文献检索”输入研究问题并按 Enter，即可自动生成检索式、检索公开学术来源并查看简洁结果表，不需要逐篇先做纳入决定。点击题名打开论文简介；配置了 AI 服务时，应用会自动翻译来源提供的题名、摘要和关键词，并将译文保存在本机。此操作会把这三项公开题录字段发送到所配置的模型服务；来源缺失的摘要或关键词不会由模型编造。点击“解析并阅读 PDF”会保存题录、获取可公开访问的 PDF，待文字解析完成后打开阅读器。复杂条件、人工筛选和来源证据可在高级区域展开核对。网络来源可能缺摘要、全文或某些指标，请以来源页面为准。浏览器扩展源码在 `desktop/electron/browser-extension/`；在 Chrome/Edge 扩展管理页开启开发者模式后，选择“加载已解压的扩展程序”并指定该目录。使用安装版时，可在“设置 → 浏览器采集”打开随程序附带的扩展目录。

结果页默认展开完整列表，可从顶部打开检索历史。列表上方可切换排序、筛选开放链接；每条题录会标明来源及摘要可用情况。勾选本页文献后，批量保存与关联操作会出现在列表上方。论文简介的保存和阅读入口位于摘要之前。

浏览论文详情页时点击扩展，先核对题录、集合和 PDF 来源，再保存到本机文献库。扩展会识别主流期刊站点当前文章的 PDF 入口；部分站点由浏览器使用当前登录会话下载，完成后验证 PDF、导入并索引。浏览器下载的原文件仍保留在系统下载目录。识别到入口不保证下载成功；付费墙或机构认证内容需要用户自己拥有相应权限。

## 阅读与整理

双击库内 PDF 开始阅读。左侧主导航和页面缩略图可分别折叠；连续阅读、缩放、选中文字、批注和笔记均在阅读器内操作。双栏对照翻译会把当前页译文缓存在本机。用户可在术语表中指定译名，随后打开受影响页面时会按新术语重新生成一次译文。

阅读助手可对选中的单词、句子、段落或可索引的页面进行翻译、总结、分析和讲解。先在“设置 → 阅读助手”填写兼容服务地址、模型及访问密钥并测试连接。AI 回答可能有误，重要结论应回到原文核对。模型请求会发送用户明确选择的材料；密钥由系统加密存储，不写入文献库。

“多文献问答”和“研究关联”用于对比库内论文及其证据。引用、主题相近或模型分析得到的联系应分别核对，不能把推断当作已证实的引用关系。

## 期刊与写作

期刊选投需要用户自己提供可用的本地期刊源库；源码与安装包不附带第三方数据库。期刊指标保留来源和年份，缺失数据不会自动推断。Word 加载项可插入和刷新引用，当前不提供 WPS 集成。

本机备份包含题录、托管附件、笔记、批注与阅读记录。重要文献建议定期备份到独立磁盘，并使用设置中的校验功能检查备份。
